# Дизайн интерфейса

- `ui-brief.md` — бриф: экраны, механики, цифры, решения по стилю.
- `ui-mvp-v1.html` — макет владельца, версия 1 (Claude Design, 2026-11-17).
  Это самодостаточная страница: откройте её в браузере. В ней есть игровой
  экран, лобби, комната ожидания, покупка, карточка актива, аукцион,
  розыгрыш порядка ходов, тюрьма, казино, шанс, рента, долги, ошибки, связь,
  итоги партии, дизайн-система и токены. Шрифты Inter и Unbounded (OFL)
  встроены в файл.

Числа в макете иллюстративные. Цены, ренты, плата за тюрьму и ставки казино
считает ядро по правилам `ROADMAP.md`; при расхождении правы правила.
