# Логотипы компаний: задание дизайнеру

Список всех компаний каталога `ua-1`, которые могут попасть на поле в MVP: всего 67. В каждой партии на поле 28 из них, выбор случайный, поэтому нужны логотипы для всех.

## Требования к файлам

- **Формат:** SVG, без растровых вставок. PNG 512×512 допустим, только если
  SVG невозможен.
- **Холст:** квадрат 1:1 (например `viewBox="0 0 64 64"`), фон прозрачный,
  поля примерно 10% по краям.
- **Читаемость:** знак должен читаться на 24–32 px. Клетки поля маленькие,
  особенно на телефоне. Длинное написание лучше заменить знаком или
  монограммой в едином стиле.
- **Фон:** логотип стоит на светлой клетке (белый или светлый градиент) рядом
  с цветной полоской группы. Он должен работать и на тёмном фоне, в списке
  «Мои активы». Если знак не работает на обоих фонах, нужны два варианта:
  `<id>.svg` для светлого фона и `<id>-dark.svg` для тёмного.
- **Имя файла:** ровно `id` из таблиц ниже, например `banks-3.svg`. Тогда
  файлы подключаются без правки кода.
- **Стиль:** единый для всех компаний (одна сетка, одна толщина линий, один
  подход к цвету). Ориентир — дизайн-система в `docs/design/ui-mvp-v1.html`.
- **Права:** это стилизованные знаки реальных брендов. Перед публичным
  релизом мы отдельно проверим использование товарных знаков. Источники
  оригиналов дизайнер может не указывать.

## Заметки

- `microfinance-4` «Миттєві Гроші» не удалось найти как отдельную компанию:
  похоже, это кредитный продукт А-Банка. Владелец может заменить её в
  каталоге. Тогда логотип нужен для новой компании.
- Где логотипа нет, игра показывает буквенный значок, так что файлы можно
  сдавать частями.
- Куда класть: `packages/game-core/src/catalog/logos/` плюс запись в
  `logos.json`. Это сделают агенты, дизайнеру достаточно прислать файлы.
