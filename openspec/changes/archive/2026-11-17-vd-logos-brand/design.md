## Design

The geometric set is a byte-identical move. Brand files come from the owner-supplied v2 set, except both microfinance-4 variants use the geometric artwork. Select the smallest measured SVGO candidate with exact 24 px and 64 px rendered pixels for each file, checking exact pixels in Chromium and resvg. The Team Lead approved 2.2 MB raw and 0.8 MB summed per-file gzip on 2026-11-17. The cross-renderer pass reduced the required per-file exceptions from 22 to 18.

Vite imports URL strings synchronously. Selecting a URL does not start an image fetch, so callers can request only their current companies. A dedicated build entry emits the assets ahead of board integration. The client container config selects brand by default in all environments, with geometric available via LOGO_SET. nginx compresses SVGs at level 6, matching the gzip budget check.
