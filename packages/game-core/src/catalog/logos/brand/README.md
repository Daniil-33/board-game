# UA-1 brand logos

The owner supplied the v2 brand icons on 2026-11-17. `sources.md` records the source and preparation of each icon.

- `source-vector` uses the original brand vector artwork.
- `vectorized-brand-reference` traces a raster brand reference into paths.
- `simplified-mascot` identifies the owner-supplied monobank mascot illustration.
- `geometric-fallback` identifies the light and dark geometric artwork used for `microfinance-4`.

For each SVG, we chose the smallest measured SVGO candidate that matched the source pixels at 24 and 64 px in Chromium and resvg. The catalog logo test records the individual size exceptions.
